# 3D Архитектурная модель: Кухонный комплекс 18.95 × 6.85 м (КК-1895-АС-01)

Интерактивная 3D-модель кухонного комплекса в масштабе 1:1 на базе **Three.js / WebGL**.

## Экспликация помещений:
- **Зимняя кухня-студия**: 9.75 × 6.05 м (58.98 м²)
- **Беседка / Терраса**: 3.60 × 6.05 м (21.78 м²)
- **Летняя кухня / барбекю**: 4.00 × 3.95 м (15.80 м²)
- **Санузел + котельная**: 4.00 × 1.90 м (7.60 м²)

## Управление 3D-сценой:
- **ЛКМ** — Свободное вращение 360° (или перемещение в режиме "✋")
- **ПКМ / Shift+ЛКМ** — Панорамирование / Перетаскивание
- **Колесико мыши** — Масштаб (зум)
- **Слои и элементы** — Управление видимостью крыши, плит перекрытия, стен, армопояса, рентгена полов и фундамента.
